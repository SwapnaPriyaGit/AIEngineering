# Python Basics Learning Guide

A comprehensive collection of Python fundamental concepts and exercises, designed for beginners looking to master the core building blocks of Python programming.

## 📚 Curriculum Overview

This folder contains sequential lessons that progressively build your Python knowledge:

### 1. **01_Heloo_Python.py** - Getting Started
- Your first Python program
- Understanding print statements
- Basic output to console

### 2. **02_Basics.py** - Variables and Data Types
- String variables
- Boolean variables
- Integer variables
- Type conversion
- Understanding `type()` function
- Exploring different data types

### 3. **03_Basics_2.py** - Additional Fundamentals
- Further exploration of Python basics
- Building on core concepts

### 4. **04_AI_Agent.py** - AI Integration with Python
- Working with AI model variables
- String interpolation with f-strings
- Building AI agent prompts
- Preparing for AI-powered applications
- Models covered: Claude, GPT, Gemini

### 5. **05_Identifier.py** - Python Identifiers
- Variable naming conventions
- Rules for valid identifiers
- Python naming standards

### 6. **06_Keyword.py** - Python Keywords
- Understanding reserved keywords
- Built-in keywords and their usage
- Keywords in control flow

### 7. **07_Literals.py** - Literals in Python
- String literals
- Numeric literals
- Special literals
- Literal types and values

### 8. **08_Operator.py** - Python Operators
- Arithmetic operators
- Comparison operators
- Logical operators
- Assignment operators
- Operator precedence

## 🚀 How to Use This Repository

1. **Start sequentially** - Begin with `01_Heloo_Python.py` and progress through each file
2. **Run each script** - Execute Python files to see outputs and understand concepts:
   ```bash
   python 01_Heloo_Python.py
   python 02_Basics.py
   # ... and so on
   ```
3. **Experiment** - Modify the code and observe how changes affect the output
4. **Take notes** - Document what you learn from each lesson

## 📋 Prerequisites

- Python 3.7 or higher installed on your system
- Basic text editor or IDE (VS Code, PyCharm, etc.)
- Command line/terminal access

## 🔧 Setup

1. Clone or download this repository
2. Navigate to the Python_Basics folder
3. Run Python scripts directly:
   ```bash
   python filename.py
   ```
